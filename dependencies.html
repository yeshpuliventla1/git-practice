Git & GitHub Basics

Git & GitHub — Quick Reference

What is GitHub?

GitHub is a cloud platform for hosting Git repositories, collaboration, pull requests, and project management.

Common Git commands 
# Clone a repository
git clone https://github.com/OWNER/REPO.git

# Basic Github commands

# See status of working tree
git status

# Stage changes
git add file.txt
git add .

# Commit staged changes
git commit -m "Short, descriptive message"

# Push commits to remote
git push origin main

# Pull latest changes
git pull origin main

# Create and switch to a branch
git checkout -b feature-branch

# Switch to an existing branch
git checkout main

# Merge a branch into current
git merge feature-branch
GitHub flow (basic)
  1. Fork or clone the repository.
  2. Create a branch for your work.
  3. Make commits and push the branch.
  4. Open a Pull Request on GitHub.
  5. Address review comments and merge.
